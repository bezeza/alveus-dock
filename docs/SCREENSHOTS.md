# Screenshots

Real screenshots are intentionally not included yet. Alveus Dock has not been launched in a live KDE Plasma session in this development environment, so a generated mockup would be misleading.

After the first Fedora 44 / Plasma 6.8.x runtime test, add genuine captures to this directory and link them from README.md.

## Capture checklist

- [ ] Horizontal dock on a clean Plasma desktop.
- [ ] Dock with several running applications and pinned launchers.
- [ ] Hover scaling and launch reaction.
- [ ] Right-click context menu.
- [ ] Appearance settings page.
- [ ] Behavior settings page.
- [ ] Vertical panel layout, if it passes runtime testing.

## Capture rules

- Capture the actual running applet, not a design mockup.
- Do not include private window titles, notifications, personal files or account details.
- Use PNG or WebP and keep images reasonably sized.
- Record the Plasma version and Fedora release used for each capture.
